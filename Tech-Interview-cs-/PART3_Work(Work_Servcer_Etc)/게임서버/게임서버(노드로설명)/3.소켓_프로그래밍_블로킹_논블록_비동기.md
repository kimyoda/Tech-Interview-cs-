## 1. 블롴킹 소켓

**블로킹 소켓(Blocking Socket)**은 소켓 함수를 호출했을 때 작업이 완료될 때까지 **해당 스레드의 실행이 멈추는(블록되는)** 소켓이다.

```
블로킹 소켓 동작

스레드: recv() 호출 (해당 구간 동안 스레드는 아무것도 못함) -> 데이터 도착 -> 반환
```

블로킷 소켓의 단점:

- 데이터를 기다리는 동안 스레드가 낭비된다
- 1000명의 클라이언트를 처리하려면 1000개의 스레드 필요
- 스레드가 많아질수록 문맥 교환(Context Switch) 비용 증가

```
블로킹 방식 - 스레드 낭비

클라이언트1 <- 스레드1 (대기 중...)
클라이언트2 <- 스레드2 (대기 중...)
클라이언트3 <- 스레드3 (대기 중...)
```
